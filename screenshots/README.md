# Screenshots

Drop app screenshots here, then reference them from the Screenshots table in the
top-level README.

Suggested filenames:

- `main.png` — camera screen with the overlay
- `gallery.png` — gallery preview with info / share / delete
- `settings.png` — settings screen

A good set for a store listing is 3-4 phone screenshots (1080x2400 or larger),
captured on a device without any personal information in them.
